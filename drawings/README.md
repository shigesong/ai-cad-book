# Drawings

TechDraw sheets and other 2D documentation exports live here.

Naming follows the chapter prefix:

- `19-fence-panel.pdf` — TechDraw exercise
- `20-fence.pdf` — FreeCAD fence sheet
- `21-deck.pdf` — FreeCAD deck framing plan
- `22-shed-plan.pdf` — BIM floor plan
- `22-shed-elevation.pdf` — BIM elevation

Keep the source `.FCStd` in `../designs/` and the exported PDF/SVG/DXF here.
Do not edit a drawing by hand; regenerate it from the model.
